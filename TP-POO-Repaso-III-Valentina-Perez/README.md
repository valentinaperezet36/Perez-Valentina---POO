# Trabajo de Repaso III · Valentina Pérez

Ejercicio 1. MaterialDigital, LibroDigital y Audiolibro. Cada subclase sobrescribe la descripción.

Ejercicio 2. MedioPago, Tarjeta y BilleteraVirtual. Cada medio muestra sus datos y comprueba que el monto sea mayor que cero.

En Eclipse, importá el proyecto como **Existing Projects into Workspace** y ejecutá el archivo Main.java de cada paquete con **Run As → Java Application**.
